# Feynman Point - End of π

In our number system, 7 represents vision, or the movement of a single light beam.

This is the direction of vision going down the number pi (π).

For example, 3.14159265 creates a 45 degree angle with 7.

(((92/(3 * 4 * 5))/65/7) * 100 ≈0.33699633699633699

The 999999 of the Feynman point embeds this same original 7 (going DOWN), while also embedding an opposite 7 (going UP), from 999999/7.

Hence, when a system uses that many digits of pi (π), it simultaneously goes up and down the circle, using 7/-7.
